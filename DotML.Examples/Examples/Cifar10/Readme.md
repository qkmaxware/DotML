## Training 
1. Download the CIFAR-10 Binary data-set from [https://www.cs.toronto.edu/~kriz/cifar.html](https://www.cs.toronto.edu/~kriz/cifar.html)
2. Extract the .tar.gz file in the raws directory
3. Ensure you have the following files in the raws directory
   1. data_batch_1.bin
   2. data_batch_2.bin
   3. data_batch_3.bin
   4. data_batch_4.bin
   5. data_batch_5.bin
   6. test_batch.bin
