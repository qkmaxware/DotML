# Pong
An example that shows the use of a genetic algorithm to train a network capable of playing the classic game "pong". 

## Training
Consists of a thousands of network clones playing pong against an increasingly difficult partner and then selecting the best performers from each generation for the next generation. No raw data is required for training. 

Use the `train` subcommand to run the training.

## Running
Running the example can be done with the `run` sub-command. This allows you to use "space" to select a gameplay option (human vs ai, human vs human, ai vs ai) and then play a game of pong. If you're playing, use W,S for paddle movement.
