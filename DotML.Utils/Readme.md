# Misc utility programs

## Backprop Generators
Python files to generate tensors for testing layer implementations against PyTorch

## Binary Merge
Merge 2 or more binary files byte by byte

## Binary Vectors 2 Dataset
Convert a binary vectors file (such as cifar-10) to a serialized training set

## Image Resize
Resize an image to a particular size

## Images 2 Classes 
Convert a folder of images into a binary serialized TrainingSet object mapping images to classes (subfolder name)

## Images 2 Images
Convert a folder of images into a binary serialized TrainingSet object mapping images to other images

## Image Slice
Slice an image into multiple sub-images of the given dimensions. 

## Safetensor
Print the contents of a safetensors file to the terminal
