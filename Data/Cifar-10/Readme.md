# Cifar-10 Dataset
The Cifar-10 dataset was converted to the "training-set" format from it's original version which can be found [here](https://www.cs.toronto.edu/~kriz/cifar.html). The dataset was not curated by me.

The dataset and the methodology are courtesy of Alex Krizhevsky (2009) and can be read about in their paper "[Learning Multiple Layers of Features from Tiny Images](https://www.cs.toronto.edu/~kriz/learning-features-2009-TR.pdf)".
